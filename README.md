# Álgebra Linear

## 1. Sobre o projeto
Desenvolver, em PHP, uma aplicação web que implemente lógicas de álgebra linear (operações com matrizes e resolução de sistemas lineares), validando cada algoritmo por meio de testes unitários com PHPUnit. O projeto tem como objetivo utilizar conhecimentos matemáticos, boas práticas e testes web e utilização de interface básica (html e css).

## 7. Estrutura do projeto
- **Config/** → arquivos de configuração do projeto.
- **Controller/** → controla as ações e faz a ligação entre a interface e o banco de dados.
- **Model/** → contém as regras e operações matemáticas.
- **templates/css/** → contém os arquivos de estilo CSS.
- **View/** → contém as páginas que serão exibidas ao usuário e testes.
- **README.md** → documentação do projeto.
